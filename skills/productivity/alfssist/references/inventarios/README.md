# Inventarios de maleta

Carpeta destino para los inventarios generados por [`../../assets/packing-list-template.html`](../../assets/packing-list-template.html) al pulsar "Guardar inventario".

Cada archivo: `inventario-<destino>-<fecha>.md`, con lo que se llevó / faltó por módulo activado en ese viaje.

Los aprendizajes recurrentes (algo que faltó dos veces, algo que sobra siempre) deberían promoverse a mano a la sección "Checklist de maleta" o "Destinos" de [`../travel-checklist.md`](../travel-checklist.md), no quedarse solo aquí.
