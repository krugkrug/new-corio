# alfvoice

Skill de voz de escritura de Alfredo Sánchez-Bella Solís: guía a Claude sobre cómo
escribir en su tono, según el modo (`[CORIO]`, `[LIQ]`, `[PERS]`, `[RAP]`) — ver
`SKILL.md`.

Es v1: generado a partir de una entrevista y 5 muestras reales de Gmail (julio 2026).
Evoluciona por ciclos de harvest — ver `HARVEST-CYCLE.md`.

## Origen

Producido con el meta-skill público [voice-as-a-skill de Eric Porres](https://github.com/ericporres/voice-as-a-skill)
(Apache 2.0) — se usó su estructura de entrevista y su plantilla de skill de voz; el
contenido de `SKILL.md` es enteramente de Alfredo. `LICENSE` se conserva por atribución.
